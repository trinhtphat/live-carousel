# Portable installation

Use the complete folder with GPT/Codex, Claude/Claude Code or a tool-enabled Gemini environment. Back up any existing installation first. Install in the skill location recognized by that runtime, then read SKILL.md and the matching adapters/ guide. Keep assets, sfx_manifest.json, engines, shared audio, fonts and licenses together.

Prepare dependencies only for the selected mode. Keep unverified media rights unverified. Run the applicable tests and report actual outputs. A chat-only environment can read the core and references as named context files but cannot render without tools. Do not claim installation on another platform or MP4 export unless performed.
