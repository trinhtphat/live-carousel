# Example · Ember & Bun — "The Inferno"
A 6-slide smash-burger launch: hook (fire + burn-in type) → bun drop & double smash → cheddar melt and
toppings rain → sauce swirl and crown drop → hero reveal with ring of fire → price stamp and order button.
The burger is built across the slides and whips into the next slide at the end of every loop.

- `PROMPT.txt` is the exact prompt that produced it.
- `00-project.js 02-hero.js 03-slides.js 04-world.js` are the project files (`new_carousel.py` copies them).
- `contact-sheet.jpg` rows = slides, columns = 0 / 25 / 50 / 75 % / last frame. `strip-preview.jpg` = the strip at 5.5 s.
