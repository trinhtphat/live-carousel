# Image source and generation

Use this guide at the image-inventory gate after topic selection, then again after the production brief and storyboard/image plan approvals when an image must be generated.

1. After the user selects a topic and before mode selection, ask whether they have usable photos, brand assets or finished slides. Inspect supplied images and order; do not replace them with generated images without an accepted reason.
2. If no images are available, decide whether HTML/vector graphics suffice or the story benefits from a generated cutout, illustration, scene or photo. Avoid generating images merely because the option exists. Use this assessment when choosing production mode and drafting the brief.
3. In the separately approved `ASSET_PLAN.md`, specify source/generated assets per slide, image treatment, crop and editable text. When `gpt-image-2-style-library` is installed, read its `SKILL.md` and relevant style reference. Offer 2–3 topic-fit directions only if the choice remains unclear. The approved palette, ratio, language and brand assets take precedence over a template.
4. After the storyboard/image plan is approved, write the chosen template's prompt with subject, composition, style, palette, text policy, ratio and negative constraints. If an image-generation tool is available, generate **one representative sample**, show the actual image, and wait for explicit user approval. Revise and repeat this gate when requested. Generate the remaining planned images only after sample approval. If generation is unavailable, provide a labelled prompt or approved HTML/vector handoff; the style library does not render images.
5. Keep headlines, infographic labels and CTA as editable video text. Prefer text-free generated artwork unless the user explicitly requests text inside it. Inspect crop, legibility, transparency and consistency across the approved sample and remaining images before the cover render.
6. Record source, licence/rights information when known, selected style/template, exact prompt, sample approval, output paths and missing assets in `ASSET_PLAN.md`. Never claim an image was generated or licensed when it was only proposed.

If the style library is absent, propose visual directions from the approved brief and state that no library template was used. This path must work in ChatGPT, Codex, Cursor, Gemini, and Claude Code without making a local Codex skill installation mandatory.
