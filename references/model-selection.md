# Model selection

Choose an available model for the work, not a permanently hard-coded winner. Do not silently switch the current session model. Check the actual runtime model list and official documentation before promising a model ID, price or access.

| Platform | Working recommendation |
|---|---|
| GPT / Codex | GPT-6.1 Sol or GPT-6 Sol for routine implementation; GPT-6 Astra for difficult architecture, reasoning and debugging when available. |
| Claude | Opus 5.5 for demanding concepts, code and overall review when available; a current lower-cost model can handle bounded edits. |
| Gemini | An available current Pro model for complex visual/code work; Flash for small edits. Verify the exact current model ID. |

These are workflow recommendations, not a benchmark ranking for this skill. Model choice is separate from image generation, 3D generation, music tools and filesystem/shell access. Use only connected/installed tools. A chat model without a render runtime can still deliver a storyboard, copy, asset prompts and exact handoff steps.

Names checked against the local Codex model list and official sources during the October 2026 update:
- https://developers.openai.com/api/docs/models/gpt-6-astra
- https://www.anthropic.com/claude-opus-5-5
- https://ai.google.dev/gemini-api/docs/models

Recheck availability at use time; do not infer that a name available in Codex is also a public API identifier.
