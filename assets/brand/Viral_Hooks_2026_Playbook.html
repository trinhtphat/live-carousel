THE PREMISE / 202602/18
BIG TYPE
DOES NOT
MAKE IT VIRAL.
Typography amplifies a strong idea. It cannot rescue a weak one. Distinct enough to notice. Clear enough to decode.
MAKE THE FORM SURPRISING. MAKE THE SENTENCE OBVIOUS.↗
THE SYSTEM / 202603/18
ONE IDEA.
FOUR SIGNALS.
VISUAL — something unexpected · TEXT — the proposition · VOICE — the tension · SOUND — a meaningful cue. For static carousels, visual hierarchy carries the first two jobs.
FIRST FRAME ≠ FIRST SENTENCE↗
THE FRAMEWORKS / 202604/18
FIVE WAYS
TO CREATE
TENSION.
01 Pattern Interrupt · 02 Contrarian Reframe · 03 Specific Open Loop · 04 Objection Mirror · 05 Proof-Loaded Loss Frame.
CHOOSE THE MECHANISM BEFORE THE FONT.↗
FRAMEWORK 01 / 202605/18
THAT LOOKS
WRONG.
GOOD.
PATTERN INTERRUPT — show an anomaly connected to the insight, then explain why. Example: “That cloudy cocktail is intentional.”
HOOK → ANOMALY → REASON → PAYOFF↗
FRAMEWORK 02 / 202606/18
MORE CHOICE
IS NOT ALWAYS
BETTER.
CONTRARIAN REFRAME — challenge a familiar belief with a defensible alternative. Hospitality: “The best cocktail menus offer fewer decisions.”
COMMON BELIEF → REVERSAL → PROOF↗
FRAMEWORK 03 / 202607/18
THE DETAIL
EVERYONE
MISSED.
SPECIFIC OPEN LOOP — name an exact, meaningful unknown. Marketing: “The 3-word label that doubled our menu inquiries.” Only use measured claims if you have actual data.
SPECIFIC DETAIL → QUESTION → ANSWER↗
FRAMEWORK 04 / 202608/18
I USED TO
BELIEVE
THIS TOO.
OBJECTION MIRROR — acknowledge the viewer’s hesitation before reframing. “I thought AI-made visuals looked cheap. Then I changed one constraint.”
ADMISSION → SHARED FRICTION → REFRAME↗
FRAMEWORK 05 / 202609/18
YOUR MENU
IS LOSING
ORDERS.
PROOF-LOADED LOSS FRAME — a relevant, verifiable downside with visible evidence. “Three ordering frictions we found in a real menu audit.”
RISK → RECEIPT → CORRECTION↗
TYPE TREND / 202610/18
CONTROLLED
DISTINCTIVENESS.
2024: look different. 2025: feel human. 2026: be recognizable AND readable. An editorial synthesis, not a platform-wide font leaderboard.
ONE TYPOGRAPHIC EVENT PER FRAME.↗
FONT PALETTE A / 202611/18
CLARITY IS
THE NEW
LUXURY.
PREMIUM EDITORIAL — Instrument Serif + Hanken Grotesk. One italic serif interruption against a stable grotesk grid. Works for luxury, hospitality and F&B.
DISPLAY / INSTRUMENT SERIF · UTILITY / HANKEN↗
FONT PALETTE B / 202612/18
THIS LOOKS
WRONG.
IT WORKS.
BOLD EXPERIMENTAL — Bricolage Grotesque + Inter. Shift width, weight or crop for one high-value phrase, never all at once.
DISPLAY / BRICOLAGE · BODY / INTER↗
FONT PALETTE C / 202613/18
THE BEST
IDEA IS
THE CLEAREST.
KNOWLEDGE & AUTHORITY — Geist + Fraunces. Use a neutral information structure; add editorial warmth only at the idea that matters.
UTILITY / GEIST · EDITORIAL / FRAUNCES↗
PLATFORM DESIGN / 202614/18
SAME IDEA.
THREE BEHAVIORS.
INSTAGRAM: poster first, explanation second. LINKEDIN: thesis first, evidence second. THREADS: thought first, graphic second. Adapt the hierarchy, not the message.
DO NOT FORCE ONE TEMPLATE ON EVERY FEED.↗
CAROUSEL BLUEPRINT / 202615/18
EIGHT FRAMES.
ONE PROMISE.
01 Hook · 02 Reframe · 03 Context · 04 Insight · 05 Example · 06 Proof · 07 Recap · 08 CTA. Each slide advances the original promise.
NO PADDING. NO REPEATED SLIDES.↗
THE COPY LAB / 202616/18
MAKE IT
SHORTER.
NOT VAGUER.
WEAK: “3 marketing tips you should know.” STRONGER: “Your first slide explains too much.” Keep the hook specific; do not manufacture unsupported numbers or results.
6–10 WORDS IS A USEFUL TEST, NOT A LAW.↗
EXPORT / QA / 202617/18
CAN YOU
READ IT
AT 25%?
Production starting points for a 1080×1350 carousel: 84px margins, 80–100px hook, 32–36px body, strong contrast. Check real rendering at feed size.
CHECK CROPS · CONTRAST · GLYPHS · SOURCES↗
FINAL CHECK / 202618/18
ONE CLAIM.
ONE PROOF.
ONE SWIPE.
Before posting: Is the point clear? Is the visual tension connected to the idea? Is the payoff real? Does each slide deserve a place? Test different hooks, not just different fonts.
ATTENTION WITHOUT TRUST IS NOT A WIN.↗

Reference notes & deployment

This guide is an editorial playbook, not an experiment proving that any font drives reach. The size values and copy limits are starting points for testing. Social performance also depends on the relevance, evidence and distribution of the post.

Font system: Instrument Serif (display) + Hanken Grotesk (utility) + IBM Plex Mono (metadata); Bricolage + Inter for experimental work; Geist + Fraunces for authority. The standalone HTML may use fallbacks when offline. The PDF preserves its embedded print typography. No standalone font binaries are distributed.

Carousel deliverables: Editable SVG and exported PNG files appear in the companion ZIP. LinkedIn can use the PDF document carousel; Instagram and Threads can use the PNGs.
